# Rise LVL UP - Critical Audit v2 (2026-02-21)

## Цель аудита
Сделать жесткую диагностику текущего MVP как "худший критик", затем зафиксировать большой, приоритетный чек-лист улучшений до уровня 10/10.

## Краткий вердикт
- Текущая оценка продукта: `3.8/10`.
- Основная проблема: ядро продуктивности и мотивации не доведено до рабочего контура (таймер, звук, голос, стабильное сохранение всех данных).
- Главное направление: сначала исправить фундамент (`P0`), потом мотивационный UX (`P1`), затем умные ускорители (`P2`).

## Диагностика (с доказательствами из кода)

### P0. Критические разрывы

1. Голосовой ввод отсутствует полностью (нет STT и маршрутизации в задачу/цель/привычку).
- Доказательства:
  - `src/ui/AppShell.tsx:30` - `src/ui/AppShell.tsx:36` (нет voice-компонента в основном UI).
  - `src/domain/types.ts:1` - `src/domain/types.ts:105` (нет voice-сущностей/интентов/состояний).
- Влияние: высокий ручной фрикшен, невозможность "сказал -> появилось в системе".

2. Модуль шума не воспроизводит аудио, только хранит флаги состояния.
- Доказательства:
  - `src/audio/noise-engine.ts:17` - `src/audio/noise-engine.ts:55` (нет `AudioContext`, узлов генерации или плеера).
  - `src/store/use-app-store.ts:378` - `src/store/use-app-store.ts:397` (`start()` не вызывается, только `setType/setVolume` и `stop` при `off`).
  - `src/ui/NoiseCard.tsx:9` - `src/ui/NoiseCard.tsx:40` (UI есть, реального звука нет).
- Влияние: пользователь видит "шум", но не получает шум.

3. Фокус-таймер без обратного отсчета и автоперехода фаз.
- Доказательства:
  - `src/ui/FocusTimerCard.tsx:60` (только текст "Сессия идет...").
  - `src/store/use-app-store.ts:328` - `src/store/use-app-store.ts:376` (таймер только start/complete/cancel, без ticking/remaining time).
  - Поиск по проекту: отсутствуют `setInterval/requestAnimationFrame` для таймера.
- Влияние: "помидор" не выполняет свою главную функцию.

4. Persistence фактически реализован только для задач.
- Доказательства:
  - `src/store/use-app-store.ts:136` - `src/store/use-app-store.ts:139` (`loadInitial` загружает только `tasks`).
  - `src/storage/repository.ts:1` - `src/storage/repository.ts:18` (операции чтения/записи только `Task`).
  - `src/storage/db.ts:16` - `src/storage/db.ts:40` (таблицы для целей/привычек/RPG есть, но практически не используются).
- Влияние: часть прогресса не переживает перезапуск/сбой, доверие к системе падает.

5. Нет анти-застоя и автоматического учета "невыполнено/просрочено".
- Доказательства:
  - `src/domain/types.ts:2` (`TaskStatus` включает `missed`), но в store нет пути установки `missed`.
  - `src/core/progress-rules.ts:36` - `src/core/progress-rules.ts:37` (штраф `task_missed` предусмотрен), но событие не генерируется.
- Влияние: система не наказывает за фактический провал задач, RPG-экономика искажается.

### P1. Высокий продуктовый долг

6. UX не ведет по "ядру дня", интерфейс состоит из независимых карточек без сценарного потока.
- Доказательства:
  - `src/ui/AppShell.tsx:30` - `src/ui/AppShell.tsx:36` (простой вертикальный стек секций без guided flow).
- Влияние: пользователю непонятно "с чего начать прямо сейчас".

7. Визуальный слой слишком базовый для мотивационного продукта.
- Доказательства:
  - `src/styles.css:1` - `src/styles.css:115` (базовые стили без выраженной иерархии, состояний, микрообратной связи).
- Влияние: низкая вовлеченность, ощущение "таблички", а не тренажера привычек.

8. Цели и задачи слабо связаны между собой.
- Доказательства:
  - `src/ui/GoalsCard.tsx:35` - `src/ui/GoalsCard.tsx:48` (ручной `+ шаг` без декомпозиции цели в подзадачи).
  - `src/store/use-app-store.ts:239` - `src/store/use-app-store.ts:275` (цель живет отдельно от task workflow).
- Влияние: цели не превращаются в ежедневные действия автоматически.

9. Привычки без streak/стабильных метрик прогресса.
- Доказательства:
  - `src/ui/HabitsCard.tsx:33` - `src/ui/HabitsCard.tsx:52` (есть только `Сделано/Пропуск/Срыв`).
  - `src/store/use-app-store.ts:293` - `src/store/use-app-store.ts:325` (лог события есть, но нет streak-механики и аналитики).
- Влияние: слабый эффект подкрепления, трудно удерживать дисциплину.

10. Тесты покрывают базовый happy path, но не закрывают критические UX-риски.
- Доказательства:
  - `src/store/use-app-store.test.ts:11` - `src/store/use-app-store.test.ts:18` (один базовый сценарий store).
  - `src/audio/noise-engine.test.ts:5` - `src/audio/noise-engine.test.ts:9` (тест только на стартовое состояние).
  - `e2e/mvp-core.spec.ts:34` - `e2e/mvp-core.spec.ts:45` (таймер тестируется как ручной "старт/завершить", не как реальный countdown).
- Влияние: регрессии вероятны при усложнении продукта.

### P2. Средний долг

11. Нет onboarding/режима "первый день", который запускает пользователя в 60 секунд.
12. Нет weekly review и ретроспективы: "что сработало/что провалилось/что изменить".
13. Нет режима "сегодняшний фокус" (single-hero task), который снижает перегруз.
14. Нет шаблонов для типовых задач и привычек.
15. Нет отчетности по времени фокуса и динамике качества недели.

## Definition of Done (10/10)
- Пользователь может за 15 секунд создать задачу голосом и увидеть ее в "Сегодня".
- Таймер реально отсчитывает время, переживает перезагрузку и ведет фазы автоматически.
- Шум реально играет и корректно управляется.
- Все сущности сохраняются и восстанавливаются без потерь.
- Есть ежедневный цикл: план -> фокус -> завершение -> рефлексия.
- RPG/привычки действительно мотивируют за счет понятной обратной связи, а не "цифр ради цифр".
