# Rise LVL UP

Личный (single-user) локальный MVP для продуктивности в формате RPG.

## Что уже реализовано

- Одностраничный интерфейс на русском.
- Hero-блок `Что делать сейчас` с главным приоритетом дня и быстрым запуском фокуса/закрытием задачи.
- Карточка `Пульс дня` с быстрым срезом: приоритеты, таймер, RPG-статус, recovery-статус и темп выполнения дня.
- Чек-лист задач и идей.
- Голосовой quick-add (в поддерживаемых браузерах): речь автоматически маршрутизируется в задачу/цель/привычку.
- В voice quick-add добавлен этап подтверждения: preview распознанной команды + `Подтвердить/Отменить`.
- Планирование `Сегодня` и `Неделя` (с лимитом 3 приоритета на день).
- В блоке `Планы` добавлена кнопка `Подобрать 3 из недели` для быстрого формирования фокуса дня.
- Добавлена карточка `Ревью дня и недели`: чеклист конца дня, перенос остатка дня в неделю и безопасное `Закрыть день` с фиксацией пропусков.
- Добавлен локальный `JSON` бэкап: экспорт и восстановление состояния из файла (`Резервная копия`).
- Автоматическая пометка просроченных приоритетов как `missed` при загрузке и мягкий RPG-штраф за невыполнение.
- Модуль целей.
- Модуль привычек (`done/skipped/relapse`) с recovery-квестом при срыве, автозавершением (задача + фокус) и автоистечением по TTL.
- Фокус-таймер с countdown, авто-переходом `фокус -> перерыв` и восстановлением активной сессии после перезагрузки.
- Для фокус-таймера добавлена `Пауза/Продолжить` без потери оставшегося времени.
- Для фокус-таймера добавлены горячие клавиши: `Space` (старт/пауза), `S` (старт), `R` (сброс).
- RPG-движок (XP, уровни, мягкие штрафы).
- Блок `RPG-прогресс` с `Сегодняшним прогрессом`, лентой последних XP-событий, `стриками привычек` и краткими `итогами недели`.
- После срыва активируется recovery-буст: первые действия на возврат в ритм получают усиленный XP-бонус.
- Модуль шумов с реальным воспроизведением через Web Audio API (off/white/pink/brown + громкость, по умолчанию выключен).
- Обновленный визуальный слой: более читаемая типографика, мягкая иерархия карточек, анимация появления и адаптивная сетка для мобильного экрана.
- Health-banner `Готовность окружения` (микрофон/аудио/IndexedDB) для быстрой диагностики перед работой.
- Для локальных данных добавлен flow защиты через Persistent Storage API (`Защитить данные`, если поддерживается браузером).
- В списке задач добавлены фильтры вида (`активные`, `день`, `неделя`, `выполненные`, `пропущенные`) для быстрого фокуса.
- Добавлены рабочие экраны (`Фокус`, `Планирование`, `Ревью`, `Все`) для снижения перегрузки и быстрого переключения контекста.
- Добавлен onboarding первого запуска (`Быстрый старт (1 минута)`) с локальным флагом завершения.
- Добавлен PWA-контур: web manifest + service worker + установка как приложение через карточку `Установить как приложение`.
- Добавлен mobile-first слой: улучшены touch-target размеры и адаптация компоновки для узких экранов.
- Добавлен `Режим фокуса`: при включении и активном таймере интерфейс автоматически сворачивается до ключевых блоков (пульс дня, текущий фокус, таймер, шум).
- При старте приложения добавлен безопасный bootstrap: сначала загрузка локального состояния, затем рендер полного интерфейса.
- Локальное хранилище ключевых сущностей через Dexie/IndexedDB (задачи, цели, привычки, логи привычек, планы, RPG, recovery-квест, аудио-настройки, последняя фокус-сессия).
- Unit-тесты (Vitest) и e2e-сценарии (Playwright).

## Технологии

- React + TypeScript + Vite
- Zustand
- Dexie (IndexedDB)
- Vitest
- Playwright

## Быстрый старт

```bash
npm install
npm run dev
```

Открыть: `http://127.0.0.1:5173`

## Проверки

```bash
# Unit tests
npm run test:run

# Production build
npm run build

# E2E tests
npm run e2e
```

## Важные заметки по e2e

Для Playwright нужен Chromium:

```bash
npx playwright install chromium
```

Скрипт `npm run e2e` автоматически поднимает локальный web-server на `127.0.0.1:4173` через конфиг Playwright.

Если в Linux-среде не хватает системных библиотек (например `libnspr4.so`), браузерные e2e не стартуют до установки этих зависимостей в ОС.
