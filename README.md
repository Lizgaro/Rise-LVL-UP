# Rise LVL UP

Productivity app with:
- simple checklist for tasks and ideas
- Pomodoro/focus timer with configurable duration
- RPG progression for real-life actions
- habit mode (build good habits)
- bad-habit recovery mode with fair penalties and comeback mechanics
- minimal UI + focus sounds (white/pink noise and similar options)
